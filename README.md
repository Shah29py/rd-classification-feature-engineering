# Case 7 — RD Classification

## Feature Engineering для классификации Разрешительных Документов

Проект выполнен в рамках стажировки 2026.

### Цель проекта

Исследовать структуру и содержание Разрешительных Документов (РД) и
выделить признаки (features), которые позволяют различать товарные группы.

Основные целевые товарные группы:

| TG ID | Товарная группа |
|---:|---|
| 4 | Парфюмерия |
| 35 | Косметика, бытовая химия и товары личной гигиены |
| 43 | Моторные масла |

Основной фокус проекта — **Feature Engineering и Feature Discovery**.
Обучение классификатора является дополнительной частью кейса.

---

## Постановка задачи

Разрешительные Документы содержат разнородную информацию:

- текстовые поля;
- структурированные атрибуты;
- информацию о продукции;
- данные о производителе и заявителе;
- сведения о типе документа;
- коды ТН ВЭД;
- другие характеристики.

Необходимо исследовать эти данные и определить признаки, которые:

1. специфичны для отдельных товарных групп;
2. помогают разграничивать несколько товарных групп;
3. могут быть использованы для последующего обучения классификатора.

В качестве эталонной разметки используется `truth_rd_data`.
